# Remainder-Growth Class (RGC)

Research-stage classification. Not a physical discovery.

## Rule

Added observational effort grows the unnamed remainder faster than the
named set. A single slice that is entirely new is only a prediction
about the unexamined stock, not a measured derivative.

## Kill

The remainder channel is saturated: discovery coefficient alpha <= 0,
or a nested rarefaction slope is ~0. Further effort does not add
unnamed entities faster than named ones.

## Do not re-issue

DPC, FCC, DCC, OAC, FPC, PDC, ANC.

## Leftover (do not mint here)

False-Saturation Class: a coarse channel with alpha <= 0 is reported
as the census closing, while a finer channel's alpha stays high.
Different kill (the finer channel is already in the same likelihood).
